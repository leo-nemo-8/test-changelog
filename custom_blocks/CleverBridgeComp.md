Before you continue, make sure your integration environment is ready.

Complete the following steps:

- Create an API key in your account settings.
- Store the API key as an environment variable.
- Confirm that your application can make HTTPS requests.
- Use a test account before sending production requests.

| Requirement          | Details                                             |
| -------------------- | --------------------------------------------------- |
| API key              | Required to authenticate API requests.              |
| HTTPS client         | Required to send requests to the API.               |
| Test account         | Recommended for validating your integration safely. |
| Environment variable | Keeps API keys out of your source code.             |

After you complete these requirements, continue with the setup steps on this page.
