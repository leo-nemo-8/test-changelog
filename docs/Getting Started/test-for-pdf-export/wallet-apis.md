# Overview

CleverTap introduces a set of Wallet APIs allowing you to integrate wallet functionality within your applications using CleverTap. These APIs enable fetching wallet details, retrieving transaction history, and crediting/debiting points in real-time. This helps enhance customer engagement with loyalty or points-based systems.

A business can use these APIs to manage reward points, enabling their customers to redeem them for discounts on future purchases. For example, a food delivery app wants to implement a loyalty rewards program to increase customer retention. Customers earn points for every order they place, which they can later redeem for discounts on future purchases.

# Wallet APIs

The Wallet APIs suite consists of the following Wallet APIs:

* [Get Wallet Details](/docs/get-wallet-details)
* [Get Wallet Transactions](/docs/get-wallet-transactions)
* [Debit/Credit Wallet](/docs/debitcredit-wallet)
